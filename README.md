# CosmetoCity Beta v1 (`cosmetocity.online`) — Antalya Main Hub & Istanbul Network

Modern, ultra-fast, mobile-first Next.js & Tailwind CSS web platform built for **CosmetoCity** (`cosmetocity.com`), tailored for international health tourism patients from the **United Kingdom (🇬🇧)** and **Germany (🇩🇪)** traveling to **Antalya, Turkey** (with optional coordination in **Istanbul**).

## 🎨 Brand Identity & Color Palette (Matched to `cosmetocity.com`)
- **Primary CosmetoCity Green:** `#36B729`
- **Signature Warm Sandal Cream:** `#F0EBD8` / `#F9F7F0`
- **Mediterranean Deep Teal Accent:** `#378AA0`
- **Sky Cyan Accent:** `#89CDDF`
- **Typography:** `Quicksand` (Google Fonts)

## 🏖️ Primary Hub: Antalya (Lara / Muratpaşa) + Optional Istanbul Network
- **Antalya Main Hub:** Direct flights from the UK & Germany to Antalya Airport (`AYT`), 15-minute VIP transfer to 5-star Lara hotels, and accredited partner hospitals (including OFM Antalya Hospital).
- **Istanbul Option:** Interactive destination switcher and dedicated WhatsApp inquiry option for patients who prefer to have their procedure in Istanbul.
