# Cosmetocity Beta v1 (`cosmetocity.online`)

Modern, ultra-fast, mobile-first Next.js & Tailwind CSS web platform built for **Cosmetocity**, tailored for international health tourism patients from the **United Kingdom (🇬🇧)** and **Germany (🇩🇪)**.

## 🚀 Tech Stack
- **Framework:** Next.js 14 (App Router) + React 18 + TypeScript
- **Styling:** Tailwind CSS (Mobile-First Responsive Design)
- **Icons:** Lucide React
- **Deployment Target:** Vercel (`cosmetocity.online`)

## ✨ Core Sections Included
1. **High-Trust Hero Section:** UK & Germany patient focus, GBP (`£`) / EUR (`€`) package pricing, JCI hospital accreditation badges, and instant language switcher (`🇬🇧 EN` / `🇩🇪 DE` / `🇹🇷 TR`).
2. **Treatments (`#treatments`):**
   - **Hair Transplant (Saç Ekimi):** Sapphire FUE & DHI Direct Implantation
   - **Dental Treatments (Diş Tedavileri):** Hollywood Smile (Swiss E-Max Veneers) & Straumann Dental Implants
   - **Medical Aesthetics (Medikal Estetik):** Ultrasonic Piezo Rhinoplasty & Non-Surgical Facial Rejuvenation
3. **Interactive Before / After Showcase (`#before-after`):** Live comparison slider and clinical case switcher for Hair, Dental, and Aesthetic procedures.
4. **Verified Patient Testimonials (`#reviews`):** Authentic reviews from London, Manchester (UK), and Munich (Germany) patients.
5. **Sticky "WhatsApp'tan Bilgi Al" CTA Button:** Always-accessible floating corner button for immediate WhatsApp lead conversion.

## 🛠️ Local Development & Build

npm install
